# 私人文件中转站

入口 `/transfer/`，独立于长期素材 `/uploads/`。静态页面在 `public/transfer/`，API 为 `/api/transfer`，服务模块为 `server/transfer.js`。沿用网站现有 ADMIN_SECRET 登录；服务端签发 24 小时 HttpOnly、SameSite=Strict 会话 Cookie，HTTPS 下加 Secure，口令不写入浏览器持久存储或下载链接。登录失败有频率限制。

支持任意文件类型、批量选择、拖放、搜索、进度与取消；文件夹需压缩。分块为 8 MiB，绕过现有 Nginx 50 MB 单请求上限，无须修改 Nginx。单文件上限 1 GiB，中转站累计声明占用上限 2 GiB（包含未完成上传预留），创建上传时保留至少 1 GiB 系统可用空间。失败上传尝试释放未完成文件；中断/关闭页面留下的未完成上传在 24 小时不活动后清理，不支持断点续传，需重新选择文件。

运行文件仅保存在 Git 忽略的 `.transfer-storage/`，不在 public、dist 或 uploads 中；不能通过静态 URL 访问。每个文件由随机 UUID 目录存放 payload 与原子更新的 meta.json；显示原文件名，但不使用原名构造磁盘路径。下载必须登录，强制 attachment/application/octet-stream，支持 Range。HTML 等内容不会作为网页运行。

五天从完成上传计时，即 120 小时。到期后立即拒绝新的下载；后台每 60 秒删除到期文件，启动时和读取列表时也清理。若服务停机，重启后补清理。已有下载流可能继续完成。计时依据服务器时间，设备端显示本地时区下的到期时间。

测试：`node --test tests/transfer.test.mjs` 覆盖认证、跨站请求拒绝、乱序分块、未完成文件禁止下载/完成、二进制字节一致、Range、零字节文件、跨会话/重启可见、容量预留、精确过期边界和清理不影响永久素材。本机 10 MiB 文件经两个分块实际传输，下载内容逐字节一致，期限为 120 小时。浏览器验证登录、列表、下载链接和 390px 手机布局无横向溢出；扩展缺少本地文件权限，自动选择文件步骤未完成，分块传输通过 HTTP 接口验证。
