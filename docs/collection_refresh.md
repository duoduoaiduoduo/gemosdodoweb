# 作品集、实验与手账升级

三个栏目通过 CollectionPage 共享响应式导航、搜索、年份筛选、排序、画廊/目录视图、每页 12 条的分页与原生详情对话框。电脑和手机使用同一套交互，作品和图片不写入后台。仍沿用公开 API、原有项目启动路由以及 focus/work 分享地址。

作品集采用书封视图、尺寸与文件大小提示、PDF 内嵌阅读、页码跳转和相邻作品集阅读。先读取 PDF 各页比例，避免横版文档的占位高度变化导致页码跳转偏移；仅渲染视口附近页面。无法读取时保留原文件入口。

实验提供独立“直接试玩”链接、详情介绍与随机探索；移除文件夹和后缀等实现信息。手账采用相纸式封面、年代筛选与随机翻页，保留作者画布排版和嵌套图片放大。空内容、无匹配结果、加载失败、失效详情链接均有明确反馈。

验证：类型检查及生产构建通过。浏览器检查了 1100px 桌面与 390px 手机，搜索、无结果重置、目录切换、随机实验、原生对话框 Escape、手账图片放大与返回。使用真实公开的 27 页 PDF 验证第 10 页跳转，目标页位于顶部控制栏下 120px，画布已渲染。隔离的 25 条手账数据验证末页 1 条、年份筛选后返回 5 条并取消分页；测试数据已恢复。公开数据的独立预览副本与测试 PDF 不发布。

发布沿用 main 分支的现有自动部署流程，仅提交页面代码与本文档；上线后核对三个正式栏目。真实触屏设备与各浏览器专项测试未覆盖。

正式服务器对 .mjs 返回 application/octet-stream，浏览器无法运行 PDF worker。通过 Vite worker 构建入口生成 .js 资源，兼容现有服务器的 JavaScript MIME 配置。
