# 牛牛牧场重设计

## 画面与玩法

将原来的满屏卡通天空、栅栏及 emoji 场景替换为悬浮草岛。使用独立 `pg-` 样式、原生 SVG 牛牛与植物，移除旧牧场的两轮累积样式。电脑端为侧边控制面板加底部工具栏；700px 以下改为草岛下方的时间面板与拇指操作区。

- 喂一口：点击草地放下草料，牛牛自主寻找、吃草并显示爱心。场上草料最多 16 份，每份三口，自动清除过期草料。
- 种朵花：点击草地种下花朵，本次最多保留 36 朵，支持清理。固定的三朵装饰花不受清理影响。
- 下点雨：切换场景雨滴。
- 来集合：短时优先响应召集，随后恢复活动。
- 昼夜：滑杆手动调节、可选自动流转；可暂停牛牛活动与环境动画。
- 认识牛牛：查看名字和留言，支持贴贴；原生 dialog 提供焦点约束、Escape 关闭与焦点返回。

读取 `/api/data` 的真实牛牛。空牧场提供三位默认小岛伙伴；加载失败有独立重试提示。投喂、种花、天气与贴贴都是本次访问状态，不写入后台数据。保留既有牛牛的姓名、留言、主要颜色、斑点与体型；形象改为新的 SVG 绘制。

## 代码

- `src/PasturePage.tsx`：数据、行为循环、工具与界面。
- `src/pasture/Cow.tsx`：牛牛形象、数据类型与默认伙伴。
- `src/pasture/Island.tsx`：树木及花朵。
- `src/pasture/pasture.css`：独立视觉与响应式布局。

## 验证

类型检查和生产构建通过。浏览器检查了 320、390、1024、1280px 布局；修正草岛横向溢出与较矮桌面窗口的工具栏位置。验证了投喂计数与草料被吃完、种花 / 清理、18 次连续投喂的 16 份上限、38 次种花的 36 朵上限、暂停、夜雨、资料卡、贴贴计数、Escape 焦点返回和中英文入口。真实手机触屏与不同 GPU 的动画表现未专项测试。本次未发布线上。

设计参考：Apple [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) 中内容层与控制层的分工。轻薄面板服务于草岛与操作，并非将所有场景表面都做成玻璃。

## 上线前步态修正

将四条腿与对应蹄子拆为独立关节组，对角腿交替摆动和抬起，躯干轻微起伏。步态直接使用移动模拟的相位，寻食时加快，停止、暂停或减少动态效果时归零；阴影保持贴地。已在浏览器核对四腿变换、相反摆幅与暂停归零，未发现运行错误，类型检查和构建通过。
