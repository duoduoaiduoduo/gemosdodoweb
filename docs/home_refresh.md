# 主页视觉与牛牛统一

桌面端将四周的浮动入口集中到顶部导航，首屏以个人介绍、两个主要操作和作品滚轮组成；淡化粒子、阴影、日期与分类标签，作品描述显示摘要，完整内容仍在详情中。保留作品筛选、详情地址、社交链接、后台解锁和备案信息。

主页游走牛牛与定制预览复用牧场的 Cow 组件，四条腿交替摆动，散步有时限和休息间隔，移动按实际帧时间计算，遇到另一头牛停下。限制近距离投喂并避免重复认领，吃完休息；点击牛牛停留并打开留言。清理离开布局的 React 牛牛实例与草料。定制面板同步新造型，支持原有牛角与尾巴选项。

手机保留作品档案交互，在介绍后加入可摸头的牛牛与牧场入口；包含开心眼睛、爱心和文字反馈，支持减少动态效果。新样式集中在 src/home.css。

验证：类型检查、生产构建及牧场 5 项行为测试通过。浏览器核对桌面布局、四条腿、定制预览的长角选项、筛选空结果和恢复、作品详情、手机摸头反馈和牧场跳转；检查尺寸切换时清除草料，避免横向溢出。预览服务使用线上公开数据的独立副本，图片引用公开源地址，没有修改线上内容。

发布沿用现有 main 分支自动部署流程；本地预览页面及独立数据副本不进入部署。

## 首屏间距修正

介绍和作品改为同一双栏网格，介绍列限制在 300–350px，列间距为 32–48px；取消旧时间轴预留的 120px 偏移，将日期收入作品卡片。首屏高度限制为 660–820px，缩减档案区顶部间距。牛牛的位置随首屏底部计算，移除与牛牛重叠的装饰文字。

## 背景衔接修正

移除限宽首屏容器上的径向背景，消除宽屏下容器边缘的竖直色块分界；导航去掉大面积圆角底板、模糊和阴影，改为透明背景与细分隔线，保持原有入口和交互。
