# 手机端重设计 · 2026-09-10

本轮替换手机端公开内容页面：首页、奖状、PDF 作品集、实验展厅、手账及各自详情。手机端使用独立 React 渲染，不再初始化旧首页交互脚本。桌面首页、后台、牧场、提案和隐藏游戏保持各自现有功能。

## 设计方向

- 内容优先：白色 / 黑色底，系统字体，明确的标题层级，22px 页面边距。
- 首页采用自然纵向浏览，图片完整显示，标题放在图片下面。
- 移除旧牌堆、甩卡、上滑展开和底部五入口悬浮栏。
- 顶部轻薄导航，菜单使用原生 dialog，提供焦点约束、Escape 关闭和返回焦点。
- 独立详情页沿用原有 `?work=` 和 `?focus=` 地址；返回列表恢复此前阅读位置。
- 分享优先使用系统分享，支持剪贴板后备方式。
- 证书和图片可全屏查看；白板保留原始排版，支持局部放大滚动。
- PDF 按需加载阅读器并逐页绘制，保留原文件入口。
- 深浅模式跟随系统，减少动态效果偏好下关闭动画；允许浏览器缩放。

参考的是 Apple 的内容层与控制层分工、清晰层次与简洁导航，并未引入 Apple 商标或复制其页面。

- https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/
- https://developer.apple.com/design/human-interface-guidelines/materials

## 代码入口

- `src/mobile/MobileSite.tsx`：公开页面、详情、导航和数据读取。
- `src/mobile/MobileMedia.tsx`：图片、原生弹层、白板、图文与视频。
- `src/mobile/MobilePdfReader.tsx`：懒加载 PDF 阅读器。
- `src/mobile/types.ts`：内容类型和展示格式。
- `src/mobile/mobile.css`：独立手机视觉系统，使用 `mi-` 前缀。
- `src/App.tsx`：沿用 `detectLayoutMode` 的 phone 分流。
- `vite.config.ts`：增加上传文件代理，使开发预览中的媒体路径可用。

旧手机牌堆的 React 结构、脚本和专属样式已删除。部分旧的二级页面样式变量仍供原组件在中等宽度下使用，不应无差别删除整个旧样式文件。

## 本轮验证

- TypeScript 检查和生产构建通过。
- 五个公开页面在 320、430、768px 宽度下均无页面横向溢出；390px 做了视觉与交互检查。
- 检查了筛选、原生菜单、语言切换、作品详情、图片放大 / 缩小 / Escape 关闭、PDF 实际绘制。
- 返回作品列表恢复原来的滚动位置（实测 844px）。
- 使用临时数据副本验证图文、图片组、手账白板和内容关联；样本已移除，未改动实际内容数据。
- 320px 白板放大后仅画布内部横向滚动，页面宽度保持 320px。
- 1280px 桌面首页仍显示原有布局及作品内容。
- 修正了缓存图片 load 事件与挂载 effect 的时序问题。

构建仍有原主包超过 500KB 的提示。手机模块及 PDF 阅读器已拆分按需加载。本轮没有发布线上，也未对独立游戏进行完整对局回归。
