# 毕业设计导师阅览与编辑

- `/graduation/review` 默认打开最新正文；`?version=版本标识` 打开对应历史版本。
- 持链接可阅读、圈画、文字批注和编辑最新版正文。旧版本只读正文，但仍可添加本版批注。
- “编辑正文”允许修改当前版本各部分标题、段落与待补充说明；保存后生成独立新版本，自动分页。旧稿六部分、参考校准稿七部分均可读取。退出编辑保留本浏览器草稿，可恢复或导出。
- “与上一版对照”按章节并排显示原文和新版，标出有变化的章节。
- 每次保存带基础版本和幂等请求编号；并发修改返回冲突，不覆盖。失败保留编辑内容，允许导出。
- 批注按版本和固定 760 × 980 页坐标隔离，旧稿批注不会套到重新分页的正文。
- 本人批注撤销凭据保存在浏览器；清除浏览器数据后不能撤销原有批注。

## 存储与维护

`.graduation-review/annotations.json` 同时保存批注与完整正文历史，已从 Git 排除，发布不覆盖；纳入服务器数据备份。原始讨论稿为 `src/research/reviewDocumentData.js`，作为不可变 v1 回退和归档，不应直接改写。服务器版本快照保存当时的正文和分页结果。

修改阅读页字体、页尺寸和正文几何布局会影响批注落点，应先设计版本化布局兼容方案。`server/review-pagination.js` 用保守行高预算分页并保留所有文字；自动拆分长段落仅用于纸面显示，原始段落保留在 sections 中供编辑与对照。

`server/graduation-publication.js` 为受控完整稿发布。服务器启动时只在基础版本仍匹配、发布编号尚未存在时追加一次；先备份运行时存储，再保留旧文档与批注。发现更晚的编辑版本则跳过，不覆盖。每次改正文或图表必须使用新发布编号；原编号对应的静态文件也应保持不变。图、表和长来源列表独立分页，原有文本版本仍沿用原布局。在线文字编辑继承本版图表与来源，忽略客户端注入的附件地址；下载链接标出文件导出日期，不暗示包含后续在线修改。

## 验证

`node --test tests/graduation-review.test.mjs` 覆盖批注持久化、幂等、权限、正文版本、并发冲突、分页文字保留和版本隔离。浏览器回归覆盖画笔/文字、刷新和跨浏览器读取、断网重试、编辑/恢复/对照、历史批注、手机布局与打印。

`node --test tests/graduation-publication.test.mjs` 另验证完整稿追加、重启幂等、冲突保护、图表与长来源分页，以及后续编辑的附件继承。

## 主页入口口令

电脑主导航、手机菜单及首页“继续看看”中的毕业设计按钮，每次点击均弹出口令框。验证接口是 `/api/graduation-entry/verify`，只控制这次导航，不给直达页面或报告 API 加登录限制。直接访问 `/graduation`、`/graduation/review` 及报告版本链接保持免口令。口令校验值仅在服务端配置中保存，不包含明文。修改口令应重新生成随机盐和 scrypt 校验值。
