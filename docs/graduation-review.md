# 毕业设计导师阅览页

- 地址：`/graduation/review`，工作台中有独立入口。
- 阅读内容：`src/research/reviewDocument.ts`。当前为明确标记的讨论稿，不是完成的开题报告。
- 功能：阅读、自由圈画、位置文字批注、本人批注撤销、显示/隐藏批注、缩放、打印、复制链接。
- 持链接即可读取与新增批注。本人撤销凭据保存在创建批注的浏览器；清除浏览器数据后不再能撤销原有批注。
- 服务端数据：`.graduation-review/annotations.json`，忽略于 Git，发布不覆盖。应纳入服务器数据备份。
- 每条批注独立写入，重复提交幂等，不使用整个列表覆盖。断网保留当前未提交操作供重试，离开页面前提示。
- 其他浏览器每十秒同步一次；在书写、文字编辑或待保存期间暂停同步，避免覆盖当前操作。

## 发布下一份报告

批注采用 760 × 980 固定纸面坐标，缩放不会改变落点。改变正文、字体、页尺寸或段落布局时，必须先归档旧版正文与页面样式，并使用新的报告版本标识：同时更新 `reviewDocument.ts` 中的 `reportRevision` 和 `server/graduation-review.js` 中的 `REVIEW_REVISION`。旧版批注存储保留，不能把旧版坐标套到新正文上。当前界面只展示当前版，旧版阅读入口需在归档时一起添加。

## 验证

`node --test tests/graduation-review.test.mjs` 验证独立写入、幂等、持久化、版本隔离、输入检查和撤销权限。浏览器回归应覆盖画笔/文字、刷新与跨浏览器读取、断网重试、不同缩放与触屏、打印排版。
