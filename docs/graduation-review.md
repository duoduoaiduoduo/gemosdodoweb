# 毕业设计导师阅览与编辑

- `/graduation/review` 默认打开最新正文；`?version=版本标识` 打开对应历史版本。
- 持链接可阅读、圈画、文字批注和编辑最新版正文。旧版本只读正文，但仍可添加本版批注。
- “编辑正文”允许修改当前版本各部分标题、段落与待补充说明；保存后生成独立新版本，自动分页。旧稿六部分、参考校准稿七部分均可读取。退出编辑保留本浏览器草稿，可恢复或导出。
- “与上一版对照”按章节并排显示原文和新版，标出有变化的章节。
- 每次保存带基础版本和幂等请求编号；并发修改返回冲突，不覆盖。失败保留编辑内容，允许导出。
- 批注按版本和固定 760 × 980 页坐标隔离，旧稿批注不会套到重新分页的正文。
- 本人批注撤销凭据保存在浏览器；清除浏览器数据后不能撤销原有批注。

## 独立论文阅览

`/graduation/thesis-review` 为硕士专业学位论文导师阅览入口，首版明确标为论文大纲草案，不表示论文或研究评价已完成。开题报告继续使用 `/graduation/review`，两个界面分别读取自己的正文、版本和批注；持链接可以阅读、批注和编辑本界面最新版。论文静态下载继续使用 `/graduation/thesis/日期/...`，与阅览路由分开，避免静态目录重定向影响直达阅读。

论文 API 为 `/api/thesis-review`，运行数据保存到 `.graduation-review/thesis-annotations.json`。开题 API 与 `.graduation-review/annotations.json` 保持独立。相同的批注编号或编辑请求编号不会跨文件混用；其他界面的版本不能用来提交本界面的正文或批注。论文浏览器草稿及撤销凭据也使用独立存储前缀。

`server/thesis-document.js` 提供初始论文大纲。`createGraduationReview` 的可选 `initialDocument` 会在首次启动时保存该版正文和当时的分页；后续重启不会用更新后的种子覆盖已有文字、页几何、版本或批注。修改已有论文须保存新版本或使用新的受控 publication 编号，并提供匹配的基础版本。在线编辑生成“论文讨论稿”版本，同时继承本版封面说明、标题、图表、格式与来源。开题未传入这些选项时继续使用原来的种子及版本命名。

论文接口采用独立容量配置：JSON 请求最多 1 MiB，每章最多 60,000 字符和 300 段，每段仍最多 10,000 字符，供后续长篇论文保存与完整分页。开题接口继续使用原来的 150 KiB 请求、每部分 20,000 字符及 100 段限制。这些限制由服务端配置决定，不能通过提交正文改变。

## 存储与维护

`.graduation-review/annotations.json` 同时保存批注与完整正文历史，已从 Git 排除，发布不覆盖；纳入服务器数据备份。原始讨论稿为 `src/research/reviewDocumentData.js`，作为不可变 v1 回退和归档，不应直接改写。服务器版本快照保存当时的正文和分页结果。

服务器数据备份应保存整个 `.graduation-review/` 目录，包含独立论文文件 `thesis-annotations.json` 与受控发布生成的备份文件。部署不能以本地草案文件替换任一运行数据文件。

修改阅读页字体、页尺寸和正文几何布局会影响批注落点，应先设计版本化布局兼容方案。`server/review-pagination.js` 用保守行高预算分页并保留所有文字；自动拆分长段落仅用于纸面显示，原始段落保留在 sections 中供编辑与对照。

`server/graduation-publication.js` 为受控完整稿发布。服务器启动时只在基础版本仍匹配、发布编号尚未存在时追加一次；先备份运行时存储，再保留旧文档与批注。发现更晚的编辑版本则跳过，不覆盖。每次改正文或图表必须使用新发布编号；原编号对应的静态文件也应保持不变。图、表和长来源列表独立分页，原有文本版本仍沿用原布局。在线文字编辑继承本版图表与来源，忽略客户端注入的附件地址；下载链接标出文件导出日期，不暗示包含后续在线修改。

## 验证

`node --test tests/graduation-review.test.mjs` 覆盖批注持久化、幂等、权限、正文版本、并发冲突、分页文字保留和版本隔离。浏览器回归覆盖画笔/文字、刷新和跨浏览器读取、断网重试、编辑/恢复/对照、历史批注、手机布局与打印。

`node --test tests/graduation-publication.test.mjs` 另验证完整稿追加、重启幂等、冲突保护、图表与长来源分页，以及后续编辑的附件继承。

`node --test tests/thesis-review.test.mjs` 验证开题与论文两个运行文件的真实隔离、论文初始版持久化、跨版本提交、批注保持、在线编辑幂等及冲突、重启不覆盖种子、长篇论文章节全量分页，以及未来论文受控发布的基准保护。原开题与批注测试仍须通过。

## 主页入口口令

电脑主导航、手机菜单及首页“继续看看”中的毕业设计按钮，每次点击均弹出口令框。验证接口是 `/api/graduation-entry/verify`，只控制这次导航，不给直达页面或报告 API 加登录限制。直接访问 `/graduation`、`/graduation/review`、`/graduation/thesis-review` 及对应版本链接保持免口令。口令校验值仅在服务端配置中保存，不包含明文。修改口令应重新生成随机盐和 scrypt 校验值。
