# 新污染物旧项目资料存档

来源：用户提供的 ChatGPT 分享记录《整理新污染物数据集与可视化》
https://chatgpt.com/s/cx_6aba23dc88448191856ec8579eb926a6

原项目文件整理于 2026-09-09 至 2026-09-10。本目录复制了最终资料包及主要数据表，保留原文件名与内容；没有把这些机器整理的条目视为已逐条核验的正式研究数据。

- `new-pollutants-materials.zip`：原项目完整资料包，含 HTML、数据表、参考页面和概念图。
- `new-pollutants-global-dataset-2026.xlsx`：原项目表格工作簿。
- `china-timeline.csv`：80 条国内政策和资料节点；日期口径、层级及限制见表内列。
- `pollutants-catalog.csv`：240 条跨清单记录。存在同一物质跨清单重复和物质组条目，不能称作 240 种独立污染物。
- `monitoring-evidence.csv`：18 条监测研究摘录；数值、介质、样本和方法不同，不可直接拼成全国趋势。
- `sources.csv`：42 条来源入口。正式引用时必须重新打开原文核对。
- `policy-timeline.csv`：22 条全球与国内政策节点。
- `china-province-coverage.csv`：31 个省级地区的资料覆盖状态；“未收录”不等于当地没有政策。

这些数据适合作为检索线索和设计研究素材。清单条目数量、政策发布频率或监测样本数，均不等于污染水平、健康风险或公众关注度。当前站点的开题论证应优先引用原始政策、论文和机构资料，不直接引用本存档的二次统计作结论。
