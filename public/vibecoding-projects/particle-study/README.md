# 流形 · 滑入混沌

V017 网页成品，来自用户提供的 source.zip。保留原始实时渲染、交互和角色资源。

稳定入口：https://gemosdodo.art/vibecoding/particle-study

通过 HTTPS 在支持 WebGPU 的浏览器中打开。拖动旋转、滚动缩放，点击“滑入混沌”进入滑板跟拍；左右方向键或 A / D 转向，空格跳跃，P 暂停。参数面板包含花朵比例、流动速度、对焦与细节调整。

角色素材来源与许可保留在 [ATTRIBUTION.md](assets/character/ATTRIBUTION.md)。

## 默认参数与手机调参

默认对焦位置约 12%（-0.92）、花朵比例 188%、流动速度 1.00、翻卷强度 1.00、松散程度 0.00、植株尺度 1.80，细节为“流畅”。“恢复默认参数”与首次加载使用同一份参数。

手机竖屏打开参数后，上方保留实时预览，下方独立滚动；较矮的横屏改为左右分栏。关闭面板后画布恢复完整尺寸。

## 火种玩法

把“火种”拖到草木上，或点击火种进入点火模式，再按住、滑动点燃。点火模式下再次点击火种可恢复拖动旋转；“重新生长”清除燃烧并恢复植被，保留当前画面参数。切换滑板或打开参数面板时停止手中的点火，已经燃起的部分继续演化。暂停会同时冻结燃烧，恢复默认参数会还原植被。

燃烧记录在原植株方向的 64 × 32 表面热量与燃料场上，随原有形态流动；包含局部传热、燃料耗尽、焦化卷缩、余烬及残烟。火焰、烟、火星在场景内接受深度遮挡并参与光圈成像，局部热羽流产生折射扰动。没有外部视频或火焰贴图依赖。
