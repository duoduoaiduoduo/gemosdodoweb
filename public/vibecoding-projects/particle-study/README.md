# 流形 · 滑入混沌

V017 网页成品，来自用户提供的 source.zip。保留原始实时渲染、交互和角色资源。

稳定入口：https://gemosdodo.art/vibecoding/particle-study

通过 HTTPS 在支持 WebGPU 的浏览器中打开。拖动旋转、滚动缩放，点击“滑入混沌”进入滑板跟拍；左右方向键或 A / D 转向，空格跳跃，P 暂停。参数面板包含花朵比例、流动速度、对焦与细节调整。

角色素材来源与许可保留在 [ATTRIBUTION.md](assets/character/ATTRIBUTION.md)。

## 默认参数与手机调参

默认对焦位置约 8%（-1.00）、花朵比例 188%、流动速度 1.00、翻卷强度 1.00、松散程度 0.00、植株尺度 1.80，细节为“流畅”。“恢复默认参数”与首次加载使用同一份参数。

手机竖屏打开参数后，上方保留实时预览，下方独立滚动；较矮的横屏改为左右分栏。关闭面板后画布恢复完整尺寸。

参数面板顶部可切换天空、纯白和纯黑背景。纯色背景直接参与场景合成，保存画面时也会保留；黑底同步使用深色控件与浅色文字。恢复默认参数会回到天空背景。

## 火种玩法

把“火种”拖到草木上，或点击火种进入点火模式，再按住、滑动点燃。点火模式下再次点击火种可恢复拖动旋转；“重新生长”在约 13 秒内依次冷却、塌落旧叶和错峰抽芽，保留当前画面参数。切换滑板或打开参数面板时停止手中的点火，已经燃起的部分继续演化。暂停会同时冻结燃烧，恢复默认参数会还原植被。

燃烧记录在原植株方向的 64 × 32 表面场上；每格持久记录热量、燃料、焦化、烟量、水分和累积热暴露，经历干燥、引燃、邻近传热和持续焦化。草叶从尖端烘黄，并以不同速度卷曲塌落。火焰和烟雾由 80³ 的持久热量/烟炱体积场驱动，经过浮力、风和涡旋平流，按场景深度进行体积积分和自遮蔽；没有外部火焰视频、贴片或贴图依赖。再生保留残烟的消散，受损草木先缩成芽，再逐渐伸长；暂停也会冻结再生进度。

火焰使用薄反应层形成分叉、断裂与亮核；热源分簇脉动，侧风和多尺度卷流驱动弯曲；额外的 20³ 压力投影将气流传给周围空气，使烟羽脱离热源继续上升。草木按每个光圈样本进行 4× MSAA 抗锯齿，烟火以独立针孔相机的四个子像素深度进行分层遮挡；深度保留 32 位浮点精度。色调映射后追加按亮度对比和边缘方向选择的抗锯齿，低对比区域保留原像素。

叶片的燃烧前沿从尖端和薄叶缘向叶根推进，卷曲、烘黄和焦化共享同一进程；窄金红灼烧线沿前沿移动，断续余烬逐渐冷却成灰黑。少量火星从当前卷曲叶片的实际网格边缘脱离，受同一气流牵引，有独立惯性、飘摆和冷却寿命；与草木共用逐光圈的 4× MSAA 和景深遮挡。暂停冻结火星，重新生长停止生成并让现有火星消退，恢复默认参数清空火星。

烧透的叶缘和叶尖会在短暂炭化后逐片碎裂，裂片边界、场景深度和阳光阴影使用同一侵蚀记录；尚未烧透的叶根保留。薄灰片从实际卷曲叶片的缺口脱落，随热流翻滚上升、逐渐冷却消散，烧尽的草叶不会永久留下完整黑草。火星的亮核、短尾与可见寿命进一步加强；暂停、清空和渐进再生同时管理焦叶、火星与灰片。

焦叶断裂现在按每片草叶的三个长条叶段持续模拟：先形成裂缝，在叶根方向的铰链上逐渐翘曲、晃动；随后保留当时的真实叶段形状断落，独立随热流上卷和翻滚。游离的焦片保持数秒，末期才继续粉化为细灰。同一块叶段连续经历挂裂、脱落与飘散，主画面、景深遮挡和阴影同步跟随。

火星使用白热亮核、饱和橙色外壳和窄炭边，在明暗背景中保持轮廓。它们从正在燃烧、挂裂和刚脱落的真实叶片姿态中释放，带有侧向惯性，再被气流带走；冷却与可见寿命延长，少量较大的热碎片交错翻动。
